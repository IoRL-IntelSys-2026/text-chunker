# Преобразование PDF через LlamaIndex 

## Что такое LlamaIndex

**LlamaIndex** — это открытая библиотека на Python для работы больших языковых моделей (LLM) с собственными данными: документами, базами знаний, файлами. 

![Логотип](LLAMA_INDEX_PDF_V1/image.png)

Работа с данными в LlamaIndex обычно проходит несколько этапов:

1. **Загрузка (loading)** — документы считываются из файлов с помощью «ридеров» (readers). Результат — объекты `Document` с текстом и метаданными (имя файла, номер страницы и т. д.).
2. **Разбиение (chunking)** — документы режутся на небольшие фрагменты (`Node`).
3. **Индексация** — фрагменты превращаются в векторы и сохраняются в индекс.
4. **Поиск и ответ** — по запросу находятся подходящие фрагменты и передаются модели.

В этом задании используется **только первый этап — загрузка и преобразование PDF в текст**. Его качество важно, потому что все следующие этапы работают с тем текстом, который удалось извлечь.

Для загрузки файлов применяется `SimpleDirectoryReader` — универсальный ридер LlamaIndex, который сам выбирает способ чтения по расширению файла. Для PDF он использует `PDFReader` на основе библиотеки **pypdf**.


## Важная тонкость при работе с форматом PDF

PDF бывают двух видов:

- **текстовые** — внутри хранится сам текст (например, документ сохранён из Word в PDF);
- **сканы** — внутри хранятся только изображения страниц (бумажный документ отсканирован, часто с подписями и печатями).

Стандартный ридер LlamaIndex (`PDFReader` / pypdf) умеет только **извлекать готовый текстовый слой**. Распознавать текст на изображениях (**OCR**) он не умеет. Поэтому для сканов страницы определяются, но текст получается пустым.

В экосистеме LlamaIndex **OCR** выполняет облачный сервис **LlamaParse** (требуется API-ключ LlamaCloud). 


## Что делает программа `convert.py`

1. Берет PDF из папки `docs/llama_index_pdf_files/` 
2. Читает их через `SimpleDirectoryReader`. LlamaIndex возвращает каждую страницу PDF как отдельный `Document`, поэтому скрипт **склеивает страницы обратно** в один текст на файл.
3. Для каждого PDF сохраняет:
   - `md/<имя>.md` — текст документа в Markdown;
   - `json/<имя>.json` — запись с текстом и метаданными.
4. Собирает **`llama_index.jsonl`** из всех `.json`: одна строка = один преобразованный PDF.
5. Формирует мини-отчёт **`report.txt`**: версии библиотек, параметры запуска, статистику по документам и автоматические предупреждения. Раздел с ручными замечаниями при повторном запуске не стирается.

### Структура результата

```
LLAMA_INDEX_PDF_V1/
├── md/                 по одному .md на каждый PDF
├── json/               по одному .json на каждый PDF
├── llama_index.jsonl   все документы набора, по строке на PDF
└── report.txt          мини-отчет
```

### Поля в каждой строке `llama_index.jsonl`

| Поле | Что означает |
|---|---|
| `doc_id` | имя файла без расширения |
| `file_name` | имя исходного PDF |
| `source_path` | путь к исходному PDF в репозитории |
| `num_pages` | количество страниц |
| `num_chars` | количество извлечённых символов |
| `tool` | инструмент (`llama_index`) |
| `tool_version` | версия `llama-index-core` |
| `reader` | использованный ридер |
| `created_at` | дата и время преобразования |
| `text` | извлечённый текст |

### Как запустить

```
pip install llama-index-core llama-index-readers-file
python convert.py
```

Программа запускается из корня репозитория. 

Подробные замечания по каждому документу — в `report.txt`.
