# Проверка ответа на вопрос о пособии по инвалидности

Вопрос: «Как подать заявление на пособие по инвалидности?»

Поиск отработал по делу. В выдаче были страницы Social Security о том, как подать заявление: онлайн, по телефону 1-800-772-1213 и в местном офисе. Рядом попала лишняя страница про ветеранов, она к способу подачи не относилась.

Модель Qwen2.5-0.5B-Instruct с генерацией ответа не справилась. Вместо пересказа найденных страниц она сочинила письмо: медицинские карты, трудовая история, дипломы, права и банковские выписки. Этого в найденных фрагментах нет. Ответ получился на английском, хотя вопрос был на русском.
