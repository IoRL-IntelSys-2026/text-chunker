# Скрытые папки

Эти папки создаёт Python и pytest сами. В списке файлов Cursor они скрыты настройкой `files.exclude` (общая настройка редактора, для всех проектов). На диске папки остаются. В репозиторий их не кладём: это не исходный код, после удаления программа создаст их снова.

| Папка | Кто создаёт | Зачем |
| --- | --- | --- |
| `__pycache__` | Python при импорте модуля | Разобранный код `.pyc`, чтобы следующий запуск шёл быстрее |
| `.pytest_cache` | pytest после прогона тестов | Память о прошлых тестах: `pytest --lf` повторяет только упавшие |
