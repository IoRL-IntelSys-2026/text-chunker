# Шаблон баг-репорта команде 1 (PRS)

Использовать, когда в `quality_report.md` по снимку РУДН `dup_ratio ≥ 2 %`
или в топ-20 групп видны шаблонные блоки парсера (меню, контакты, подвал).

## Заголовок

`[PRE→PRS] Повторяющиеся чанки в <snapshot_id> / <collection>`

## Суть

Кратко: что повторяется и почему это похоже на недочищенную обвязку страницы.

## Цифры

- ссылка на `quality_report.md`
- `dup_ratio`: …
- размер топ-группы (число документов): …

## Примеры (3–5)

Для каждой группы из топа:

| doc_id / url | фрагмент текста (до 200 символов) |
| --- | --- |
| … | … |

## Ожидание

PRS правит очистку (`clean.yaml` / селекторы). PRE сами повторы из индекса не вычищают.

## Не делать

Не просить PRE «удалить дубли из Qdrant» как основное решение — источник в снимке/очистке.
