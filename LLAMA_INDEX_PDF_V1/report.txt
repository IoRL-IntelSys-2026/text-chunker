Скрипт использует стандартный способ LlamaIndex (через библиотеку pypdf), который умеет только доставать готовый текст из PDF. 
Читать текст с картинок он не умеет. Поэтому у сканов получилось 0 символов: страницы есть (3 и 6), а текста в них для программы нет.
С помощью OCR (распознавания текста на картинках) это можно исправить. 
В экосистеме LlamaIndex это делает LlamaParse, но для него нужен ключ LlamaCloud. 
Есть и бесплатные локальные инструменты (например, Tesseract), но их сложнее установить.
